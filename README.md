# Maritime Semantic Segmentation

Dense semantic segmentation for maritime scenes — classifying pixels into water, sky, ship, buoy, land, and other categories. The project covers the full pipeline: dataset, training, and visual predictions.

---

## Repository Structure

```
├── train.py                  # Training script
├── predict.py                # Prediction / visualisation script
├── prompt.txt                # The prompt used to generate the base code
├── models/
│   ├── best_model_fpn.pth         # Best FPN + ResNeSt50 checkpoint
│   └── best_model_unetpp.pth      # Best UNet++ + MobileNetV3 checkpoint
├── finalModelPredictions/    # Output images produced by the two final models
├── dataset.zip               # Full dataset (train / validate / test splits)
└── README.md
```

### What each file does

**`train.py`** — Trains a UNet++ segmentation model on the maritime dataset. Handles data loading, augmentation, loss computation, metric tracking, checkpointing, and final test evaluation. Outputs a `best_model.pth`, a `last_model.pth`, per-epoch logs in `history.json`, and a final `test_results.json`.

**`predict.py`** — Loads a trained checkpoint and runs inference on a folder of images. Saves side-by-side comparison images (original + colour-coded prediction overlay) and raw mask PNGs. Optionally computes per-image mIoU if ground-truth masks are provided.

**`prompt.txt`** — The prompt submitted to Claude to generate the initial base code for this project.

**`models/`** — Contains the two best-performing model checkpoints from the experiments:
- FPN with ResNeSt50 encoder
- UNet++ with MobileNetV3 encoder

**`finalModelPredictions/`** — Visual prediction outputs generated by the two final models on the test set, produced using `predict.py`.

**`dataset.zip`** — The full 1693-image maritime dataset, pre-split into train / validate / test folders. Each split contains an `images/` subfolder and a `masks/` subfolder. Masks are single-channel PNGs where each pixel value is a class ID (0–7).

## Step 1 — Training

Unzip the dataset first:

```bash
unzip dataset.zip
```

This gives you the following structure (do not change it):

```
dataset/
├── train/      images/  masks/
├── validate/   images/  masks/
└── test/       images/  masks/
```

Run training with your chosen encoder:

```bash
python train.py \
  --data_root ~/maritime/dataset \
  --output_dir ~/maritime/output/unetpp_resnet34 \
  --encoder resnet34 \
  --epochs 100 \
  --batch_size 8 \
  --lr 1e-4
```

After training finishes, the output folder will contain:

```
output/
├── best_model.pth       # Checkpoint with highest validation mIoU
├── last_model.pth       # Checkpoint from the final epoch
├── history.json         # Per-epoch loss, mIoU, and class metrics
└── test_results.json    # Final test set evaluation + efficiency stats
```

**Resuming a run:**

```bash
python train.py \
  --data_root ~/maritime/dataset \
  --output_dir ~/maritime/output/unetpp_resnet34 \
  --encoder resnet34 \
  --resume ~/maritime/output/unetpp_resnet34/last_model.pth
```

**Common encoder options:**

| Encoder | Speed | Accuracy |
|--------|-------|----------|
| `resnet34` | Fast | Good baseline |
| `timm-resnest50d` | Medium | Strong |
| `timm-efficientnet-b2` | Medium | Efficient |
| `timm-mobilenetv3_large_100` | Very fast | Lightweight |

## Step 2 — Prediction

Once you have a trained checkpoint, run `predict.py` on a folder of images:

```bash
python predict.py \
  --checkpoint ~/maritime/output/unetpp_resnet34/best_model.pth \
  --input_dir  ~/maritime/dataset/test/images \
  --output_dir ~/maritime/predictions \
  --encoder    resnet34
```

To also compute per-image mIoU, provide the ground-truth masks:

```bash
python predict.py \
  --checkpoint ~/maritime/output/unetpp_resnet34/best_model.pth \
  --input_dir  ~/maritime/dataset/test/images \
  --mask_dir   ~/maritime/dataset/test/masks \
  --output_dir ~/maritime/predictions \
  --encoder    resnet34
```

Each image produces two output files:

- `<name>_compare.png` — side-by-side view of the original image and the prediction overlay, with a colour legend and mIoU score
- `<name>_mask.png` — raw predicted mask as a single-channel PNG (pixel values = class IDs)

> **Important:** the `--encoder` flag in `predict.py` must match the encoder used during training, otherwise the checkpoint will fail to load.
